# Calorator

Разработка пользовательского интерфейса приложения Calorator на языке C# с использованием Windows Forms (.NET 8).

=-=-= Реализованные возможности =-=-=
- Ведение дневника питания.
- Поиск продуктов по названию и штрихкоду.
- Просмотр статистики КБЖУ.
- Добавление и удаление записей.
- Настройка профиля пользователя.

=-=-= Структура проекта =-=-=
- UI — формы и элементы интерфейса.
- Models — модели данных.
- Services — обработка действий пользователя.
- Contracts — интерфейсы взаимодействия компонентов.

P.S.
Текущая версия использует данные в памяти. Подключение базы данных и распознавания продуктов по фотографиям предусмотрено для дальнейшей интеграции.
